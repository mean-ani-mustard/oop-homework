# OOP Homeworks

Object-Oriented Programming coursework (Free University of Tbilisi). Each
folder is a self-contained assignment with its own `master`/`feedback`
history preserved from the original per-assignment repositories.

| # | Topic | Highlights |
|---|-------|------------|
| [hw-01](hw-01) | Java fundamentals | `Point`, `CharGrid`, `Taboo`, `StringCode` — basic classes and unit tests (JUnit 3) |
| [hw-02](hw-02) | Tetris | `Board`/`Piece`/`Brain` — a Tetris engine plus a heuristic-driven AI brain |
| [hw-03](hw-03) | Sudoku + Swing/JDBC | A backtracking Sudoku solver with a GUI, and a MySQL-backed "Metropolis" database app |
| [hw-04](hw-04) | Concurrency | `Bank`/`Cracker` — thread-safe bank accounts and a multithreaded password cracker |
| [hw-05](hw-05) | Java web apps | Two Maven/Servlet webapps: a login system and a MySQL-backed shopping cart |

All assignments compile and their unit tests pass (DB-dependent tests in
hw-03/hw-05 require a local MySQL instance with the provided `.sql` files
loaded).
